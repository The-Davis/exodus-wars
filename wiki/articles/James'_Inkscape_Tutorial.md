So, you've decided to use Inkscape to draw? Then congratulations! You've chosen a powerful vector image editing tool that is both free and Open Source!

This tutorial will walk you step-by-step through some common tools for creating cell-shaded lineart. Let's get started!

= Part 1: The Bare Bones =

The first step in any drawing is "what will I draw?" I've chosen to do a "deviantID" for my [ http://www.deviantart.com/ deviantArt ] page. I'll walk you through the process I use, and you can alter it for your own needs.

== Getting Started ==

Start up Inkscape. By default, it loads with a standard-sized blank workspace. Don't worry about how large it is, you can change it whenever you want. The default file format is known as an "SVG", or Standard Vector Graphic. It has a single layer. This is the first thing we'll change.

=== Manage Your Layers ===

[[Image:InkscapeTutorial1.png|100px|right|thumb|Click to enlarge.]]

Working with multiple layers is an easy way to avoid mistakes, and to turn on and off unwanted portions as you go. By default, you have a single layer called "Layer 1". Let's change that to two layers, one called "Guidelines", and one called "Lineart."

To change layers, go to the "Layer" menu, then select the "Layers" option. The keyboard shortcut is "Shift + Ctrl + L".

Once you have the layers menu up, you have several options available to you. The "eye" button next to the layer name will make the layer invisible or visible. This is useful if you want to hide some parts (say shoes) while working on something underneath it (socks?). 

[[Image:InkscapeTutorial2.png|100px|right|thumb|Click to enlarge.]]

The "lock" button next to the layer name will keep the layer from being edited. This is very useful! I suggest always locking a layer if you are not working on it.

The "plus" button on the bottom of the screen will add a new layer. The "minus" button will remove a layer (be careful here!). The arrow buttons will raise or lower layers.

You can rename a layer by clicking on its name. Do that with "Layer 1" and rename it "Guidelines". Next, hit the "plus" button to add a second layer, and name it "Lineart". Close the layers screen to return to your editing window. [[Image:InkscapeTutorial3.png|100px|right|thumb|Click to enlarge.]]

=== Guidelines ===

Drawing some good guidelines will get you started on how the drawing will work. If you have some poser software or a posing dummy, this can help you with a person. Feel free to copy this step by step, or use a posing dummy (about $5-10 at your local art store) to get an idea of how joints work.

I use the Elipses/Circle Tool (F5 key or the pink circle on the toolbar) and the Freehand/Pencil Tool (F6 key or the pencil on the toolbar) to do a rough outline of where the head, chest, shoulders, elbows, hands, hips, knees, ankles, and toes will be located, along with lines of how they will balance.

[[Image:InkscapeTutorial4.png|400px|center|thumb|See how guidelines already make it look like a person's waiting to pop out? (click to enlarge)]]

This is also a good time to point out the layer indicator. It's in the bottom-left hand of the screen (see the arrow in the picture above?) This also allows you to lock/unlock and show/hide the layer you have selected. Make sure you're working in the layer you want to use.
