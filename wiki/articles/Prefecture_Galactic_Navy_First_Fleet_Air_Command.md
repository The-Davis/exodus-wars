Prefecture Navy
 
First Fleet Space Command

    The First Fleet Space Command is meant to be the balance between fighter and warship combat.  The vanguard of the Prefecture Navy has no specific role, so its fighters must be ready for anything.
    Rear Admiral Oswald is a long-time veteran pilot, bred and trained in the Alpha Centauri Clone Army.  She is an example of the typical clone soldier--rather normal with no outstanding personality traits.

Commanding Officer: Rear Admiral Lisa Oswald
